How to Convert Your Robinhood Transaction Files

1

Prepare Your File

  1. Log in to your Robinhood account
  2. Go to Account → Reports and Statements
  3. Select account type, start date, and end date
  4. Click Generate Report
  5. You'll be notified when your report is ready to download
2

Upload Your File

Once your file is downloaded, upload it or drag and drop into the upload area.

3

Select Output Format

Choose your preferred output format:

  • CSV - For spreadsheet applications
  • JSON - For developers and APIs
  • Both - Get files in both formats
4

Download & Verify

Your converted file will download automatically. Please verify the data for accuracy.

We never store or save your transaction data.

File Format Specifications

1. Input CSV Format (Robinhood)

The converter expects a CSV file from Robinhood with the following columns in this exact order: Activity Date, Process Date, Settle Date, Instrument, Description, Trans Code, Quantity, Price, Amount

Note about cash dividends (CDIV): The Description field for cash dividends should be in the format:
Cash Div: R/D YYYY-MM-DD P/D YYYY-MM-DD - [shares] shares at [amount]
Example: Cash Div: R/D 2025-04-10 P/D 2025-04-11 - 299.920038 shares at 0.216883
