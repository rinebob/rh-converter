Is your broker's transaction file format not suitable for your needs? Don't want to spend the time reformatting it? With Trade Data Converter you can easily convert your poorly formatted transaction .csv files into properly formatted and organized .csv and/or .json files suitable for importing into another app or using as a data set for an app.

Upload your file, and we'll transform it into clean, structured data. Transactions are automatically categorized into standard and dividend activity, with dates and numbers formatted for easy use.

We currently only support Robinhood but we're eager to add more brokers. On the Brokers tab you can request support for a new broker and upload a sample transaction .csv file and we'll get right on it.
