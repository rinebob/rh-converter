1. Input CSV Format (From Brokerage)

The converter is designed for CSV files from popular brokerages that use the following columns in this exact order: Activity Date, Process Date, Settle Date, Instrument, Description, Trans Code, Quantity, Price, Amount

Note about cash dividends (CDIV): The Description field for cash dividends should be in the format:
Cash Div: R/D YYYY-MM-DD P/D YYYY-MM-DD - [shares] shares at [amount]
Example: Cash Div: R/D 2025-04-10 P/D 2025-04-11 - 299.920038 shares at 0.216883

Column Name {{element.name}} Description {{element.description}}
info Note: The column order in your CSV file must match exactly as shown above.

2. Output CSV Format - Regular Transactions

Converted regular transactions will include these columns:

Column Name {{element.name}} Description {{element.description}}

3. Output CSV Format - Dividend Transactions

Converted dividend transactions will include these columns:

Column Name {{element.name}} Description {{element.description}}
