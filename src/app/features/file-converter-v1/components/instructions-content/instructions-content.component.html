How to Convert Your Transaction Files

1

Prepare Your File

  1. Log in to your brokerage account
  2. Go to Account → Reports and Statements (or a similar section)
  3. Select the account, date range, and other relevant filters
  4. Generate and download your transaction history as a CSV file
2

Upload Your File

Once your file is downloaded, upload it or drag and drop into the upload area.

3

Select Output Format

Choose your preferred output format:

  • CSV - For spreadsheet applications
  • JSON - For developers and APIs
  • Both - Get files in both formats
4

Download & Verify

Your converted file will download automatically. Please verify the data for accuracy.

We never store or save your transaction data.
